Page metadata

Sets the browser title, search description, and social-share image per page. Applied live in this browser; use “Copy tags” to bake them into the HTML at launch so search engines see them.

Copy editor

Edit the words directly on any page. Click a page below — it opens in edit mode where you can click any headline or paragraph and type over it. Changes save to this browser and preview instantly. To publish for everyone, hit “Export edited copy” and it gets baked into the site.

Social links
